What is a Caesar Cipher
The Caesar Cipher is one of the oldest ways to hide a message. You choose a number called a **shift**.
Then each letter in your message is moved by that many positions in the alphabet.

Example with shift = 3:
- A → D, B → E, C → F, ..., X → A, Y → B, Z → C

To **decrypt**, you move letters backwards by the same shift.

Encrypting and decrypting text with any shift (positive or negative)
Preserving spaces, punctuation, numbers, and case (A/Z wrap around correctly)
